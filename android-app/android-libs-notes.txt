Hardening
- Android arm64 builds in this tree use arm_control_flow_integrity = "standard"
- External static libs have to be compiled with:
  -mbranch-protection=standard
- The resulting archives have to expose:
  AArch64 feature: BTI, PAC

Checks
- readelf -n <stable-prefix>/prefix/lib/libvpx.a
- readelf -n <stable-prefix>/prefix/lib/libavcodec.a
- rg "CONFIG_(EQ|FORMAT|PAD|SCALE|TRANSPOSE)_FILTER" <ffmpeg-build>/config_components.h

Usage
- The prefix is the install location for the external Android libs.
- FFmpeg, libvpx, and opus install headers and static libraries there.
- GN args point the Android native build at that prefix through:
  ffmpeg_include_dirs
  ffmpeg_lib_dirs
  libopus_include_dirs
  libopus_lib_dirs
  libvpx_include_dirs
  libvpx_lib_dirs
- Gradle does not take the prefix directly.

Good APK build commands
- Build FFmpeg 8.1 in a clean build directory:
  mkdir -p ~/android/opt-81/build/ffmpeg-8.1-nofilter-bti
  cd ~/android/opt-81/build/ffmpeg-8.1-nofilter-bti
  ~/android/opt-81/src/ffmpeg-8.1/configure [the FFmpeg 8.1 no-filter flags above]
  make -j"$(nproc)"
  make install
- Build libvpx 1.16.0:
  mkdir -p ~/android/opt-81/build/libvpx-1.16.0-bti
  cd ~/android/opt-81/build/libvpx-1.16.0-bti
  ~/android/opt-81/src/libvpx-1.16.0/configure [the libvpx flags above]
  make -j"$(nproc)"
  make install
- Build opus 1.6.1 from its source tree:
  cd ~/android/opt-81/src/opus-1.6.1
  ./configure [the opus flags above]
  make -j"$(nproc)"
  make install
- Point GN at the prefix with these args in out/android/args.gn:
  ffmpeg_include_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/include" ]
  ffmpeg_lib_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/lib" ]
  libopus_include_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/include/opus" ]
  libopus_lib_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/lib" ]
  libvpx_include_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/include" ]
  libvpx_lib_dirs = [ "/home/mst/android/opt-81/prefix-nofilter/lib" ]
- Build the native library:
  ninja -C out/android libcontrolcast.so
- Build the APK from android-app:
  ./gradlew assembleDebug
