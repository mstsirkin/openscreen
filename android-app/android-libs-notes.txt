Hardening
- Android arm64 builds in this tree use arm_control_flow_integrity = "standard"
- External static libs have to be compiled with:
  -mbranch-protection=standard
- The resulting archives have to expose:
  AArch64 feature: BTI, PAC

Checks
- readelf -n <stable-prefix>/prefix/lib/libvpx.a
- readelf -n <stable-prefix>/prefix/lib/libavcodec.a
- rg "CONFIG_(EQ|FORMAT|PAD|SCALE|TRANSPOSE)_FILTER" <ffmpeg-build>/config_components.h

Usage
- The prefix is the install location for the external Android libs.
- FFmpeg, libvpx, and opus install headers and static libraries there.
- GN args point the Android native build at that prefix through:
  ffmpeg_include_dirs
  ffmpeg_lib_dirs
  libopus_include_dirs
  libopus_lib_dirs
  libvpx_include_dirs
  libvpx_lib_dirs
- Gradle does not take the prefix directly.
